# 계획은 J가

공휴일과 주말을 이어 연차를 가장 적게 쓰고 오래 쉬는 날을 찾고, 그 연휴에 갈 곳과 하루 일정까지 짜 주는 웹 앱이다.

운영: https://holiday-trip.vercel.app

## 할 수 있는 것

1. 날짜를 고른다. 한 해의 연휴를 모아 보여 주고, 연차를 더 쓰면 얼마나 길어지는지도 알려 준다.
2. 갈 곳을 고른다. 출발지(서울·부산·강릉 등 17개 도시)에서 닿을 만한 거리 안에서 연휴와 겹치는 축제가 많은 지역부터 추천한다.
   - 「내 위치로」를 누르면 휴대폰 위치를 출발지로 쓴다. 좌표는 약 1km(소수 둘째 자리)로 줄여 주소(`?from=here:위도,경도`)에만 남기고 저장하지 않는다. 출발지 이름은 카카오 좌표→행정구역으로 「종로구 근처」처럼 붙인다.
   - 거리는 차로 걸리는 시간으로 고른다. 칩은 「차로 2시간」「차로 4시간」「어디든」이고, 처음에는 연휴 길이에 맞는 칩(이틀 이하 2시간, 사흘 4시간, 나흘 이상 어디든)이 골라져 있다. 제주는 「어디든」에 사흘 이상일 때만 나온다. 조건에 맞는 지역은 개수 제한 없이 모두 보여 준다.
   - 출발 도시에서 시·군·구까지의 시간과 도로 모양은 `scripts/build-drive-routes.mjs` 로 미리 계산해 `src/contexts/destination/infrastructure/drive-routes/` 에 둔다. 오픈스트리트맵 도로를 로컬 OSRM 으로 계산한 막히지 않을 때 기준이고, 실행 중에는 길찾기를 부르지 않는다. 카카오 길찾기·주소 검색 결과는 저장하면 안 되므로 쓰지 않는다. 「내 위치」 출발과 표에 없는 곳은 직선 거리로 어림하고 지도에 점선으로 잇는다.
3. 일정을 본다. 관광지와 식당과 카페와 숙소를 가까운 순으로 이어 하루 일정을 짜고 지도에 동선을 그린다.
   - 식당은 카카오 「맛집」 검색 결과 중 식사 칸에서 가까운 곳을 고른다. 빵집·디저트·카페·술집과 체인 지점은 뺀다.
   - 카페 칸이 하루 하나 있다(기본은 점심 뒤, 「여행 취향」으로 때를 바꾸거나 뺀다). 카카오 「카페」 검색 결과 중 가까운 곳을 고르고 체인 지점과 그날 관광지로 넣은 곳은 뺀다. 카카오 키가 없으면 관광공사 카페에서 찾는다.
   - 「여행 취향」 시트에서 고르면 일정을 다시 짠다. 고른 것만 반영하고, 고른 값은 주소(`?with=kids&pace=relaxed…`)에 남아 저장·공유에도 이어진다.
     - 여행 전체: 누구와(아이와면 산행을 빼고 테마파크·체험을, 부모님과면 레저·산행을 빼고 실속형 숙소는 뒤로), 속도(여유롭게는 오후 관광을 빼고, 꽉 차게는 저녁 뒤 밤 산책을 더한다), 좋아하는 것(자연·역사·전시·체험·쇼핑·시장)
     - 날마다: 못 먹는 음식(해산물·고기·매운 음식 — 그날 식당에서 꼭 뺀다), 디저트(안 먹음·점심 전·후·저녁 전·후)
     - 볼거리 성격은 관광공사 신분류, 음식은 카카오 분류와 상호로 어림한다. 반려동물 동반은 관광공사 반려동물 API 신청 뒤에 넣는다.
   - 숙소는 첫 밤 장소에서 15km 안이면 종류(호텔·한옥 → 펜션 → 그 밖 → 모텔) 순으로 고르고, 처음에는 매일 같은 곳에 묵는다. 고른 숙소에는 카카오맵 「별점과 리뷰」 링크를 붙인다.
   - 장소마다 종류 뱃지, 한 줄 소개, 주소(복사·지도 열기)를 보여 준다.
   - 칸마다 근처 다른 곳으로 바꿀 수 있다. 숙소도 밤마다 따로 바꾼다. 바꾼 결과는 주소(`?pick=`)에 남는다.
   - 출발 10일 안이면 기상청 예보를 붙인다. 비 오는 반나절에는 실내 장소를 고르고, 축제 칸은 그대로 둔다.
   - OpenAI 키가 있으면 하루마다 짧은 소개 글을 붙인다. 칸을 직접 바꾸거나 취향을 고른 일정에는 붙이지 않는다(조합마다 부르면 비용이 는다).
4. 카카오로 로그인하면 일정을 저장하고 찜해 둘 수 있다. 저장하면 공유 페이지(`/t/{id}`)가 생긴다.
   - 로그인할 때마다 카카오 계정 고르기 화면을 띄우고, 찜 화면 위에 지금 로그인한 계정(닉네임)을 보여 준다. 휴대폰과 PC가 다른 카카오 계정이면 찜 목록도 다르기 때문이다.
   - 「카톡 보내기」로 친구 선택 창을 바로 연다. 「링크 공유」는 휴대폰에서 기본 공유 창을 열고, PC에서는 링크를 복사한다.
   - 「캘린더에 추가」로 구글 캘린더에 여행 기간을 하루 종일 일정 하나로 넣는다. 설명에는 날마다 갈 곳과 일정 링크가 들어간다. 공유받은 사람도 쓸 수 있다.
   - 링크를 붙여 넣으면 메신저 미리보기에 일정 제목과 이미지(`opengraph-image.tsx`)가 뜬다. 공유 페이지는 검색엔진에 올리지 않는다.

## 스택

Next.js 16(App Router·Turbopack·`use cache`) · React 19 · Tailwind CSS 4 · Drizzle ORM + Postgres · Vitest · Vercel(서울 리전 `icn1`)

바깥 데이터는 세 곳에서 받는다.

- 공공데이터포털: 천문연 특일, 관광공사 국문 관광정보, 기상청 단기·중기예보
- 카카오: 지도, 로컬(맛집·카페), 모빌리티 길찾기, 로그인, 카카오톡 공유
- OpenAI: 하루 소개 글(선택)

## 로컬에서 실행

Node 24 이상이 필요하다.

```bash
cp .env.example .env.local     # 아래 「환경변수」를 채운다
docker run -d --name holiday-trip-db -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=holiday_trip -p 54329:5432 postgres:17-alpine
npm install
npm run db:migrate             # .env.local 의 DATABASE_URL 에 스키마를 만든다
npm run dev                    # http://localhost:3000
```

DB 없이도 날짜, 갈 곳, 일정 화면은 뜬다. 로그인과 저장과 찜만 DB를 쓴다.

비 오는 날 화면은 실제 예보가 있어야 보인다. `.env.local` 에 `WEATHER_PREVIEW=mixed`(또는 `rain`)를 넣고 dev 서버를 다시 켜면 기상청 대신 가짜 날씨로 채운다. Vercel 에서는 이 값을 무시한다.

## 환경변수

로컬은 `.env.local`, 배포는 Vercel 프로젝트의 Environment Variables 에 넣는다. 키 값은 커밋하지 않는다(`.env*` 는 `.gitignore` 에 있다).

| 이름 | 필요할 때 | 쓰임 |
|---|---|---|
| `DATA_GO_KR_SERVICE_KEY` | 항상 | 공공데이터포털 일반 인증키. 「Decoding」 키를 넣는다(코드가 URL 인코딩한다). |
| `NEXT_PUBLIC_KAKAO_MAP_KEY` | 항상 | 카카오 JavaScript 키. 지도와 카카오톡 공유에 같이 쓴다. 브라우저에 공개되므로 카카오 콘솔에서 사이트 도메인을 제한한다. |
| `KAKAO_REST_API_KEY` | 선택 | 카카오 REST 키. 맛집·카페 찾기와 차 이동 시간과 로그인에 쓴다. 없으면 맛집·카페는 관광공사 음식점으로 찾고, 이동은 직선 거리로만 보여 주고, 로그인 버튼을 숨긴다. |
| `KAKAO_CLIENT_SECRET` | 로그인 | 카카오 콘솔 「보안 → Client Secret」. |
| `AUTH_SECRET` | 로그인 | 세션 쿠키 서명 키. 32자 이상 무작위(`openssl rand -base64 32`). 없으면 로그인 버튼을 숨긴다. |
| `DATABASE_URL` | 저장 | Postgres 주소. 운영은 Vercel Storage 의 Neon 이 넣어 준다. |
| `OPENAI_API_KEY` | 선택 | 하루 소개 글. 서버에서만 쓴다. OpenAI 대시보드에서 월 사용 한도를 걸어 둔다. |
| `WEATHER_PREVIEW` | 로컬 전용 | `rain` 또는 `mixed`. 위 「로컬에서 실행」 참고. |

카카오 콘솔에는 두 가지를 등록한다. 둘 다 로컬 주소(`http://localhost:3000`)와 운영 주소를 같이 넣는다.

- 「플랫폼 → Web → 사이트 도메인」: 이 도메인에서만 지도가 뜨고 카카오톡 공유가 보내진다.
- 로그인 Redirect URI: `<사이트 주소>/api/auth/kakao/callback`. 받는 정보는 회원 번호와 닉네임(필수 동의)뿐이다.

## 구조

바운디드 컨텍스트마다 domain, application, infrastructure 레이어로 나눈다.

```
src/
  app/                    화면. 컨텍스트는 공개 API(index.ts)로만 부른다
    _components/          화면 조각(카드, 지도, 스켈레톤 등)
    actions.ts            서버 액션(일정 저장, 찜하기, 탈퇴)
    t/[id]/               공유 페이지와 미리보기 이미지
    api/auth/             카카오 로그인과 콜백, 로그아웃
  contexts/
    calendar/             공휴일과 연휴 계산
    destination/          출발지와 축제로 갈 곳 추천
    itinerary/            하루 일정 짜기, 날씨, AI 소개, 일정 저장·공유·찜
    account/              카카오 로그인 사용자
      (컨텍스트마다 같은 모양)
      index.ts            공개 API이자 조립 루트(포트에 구현을 꽂는다)
      domain/             순수 규칙. 프레임워크와 바깥 레이어를 모른다
      application/        유스케이스. 읽기는 직렬화할 수 있는 View 로 돌려준다
      infrastructure/     포트 구현(공공데이터, 카카오, OpenAI, Drizzle)
  shared/
    kernel/               공유 커널. 좌표, 여행 기간, 날짜 표기, 한국어 조사
    public-data/          공공데이터포털 호출 공통(인증키, 거절 코드, 실패를 값으로)
    tour-api/ kma/ kakao/ 관광공사, 기상청, 카카오모빌리티 클라이언트
    db/ auth/             Drizzle 클라이언트와 스키마, 세션 쿠키
```

- 의존은 `app → contexts/<x>/index → application → domain ← infrastructure` 한 방향이다. `eslint.config.mjs` 의 `no-restricted-imports` 가 거꾸로 가는 import 를 막는다.
- 컨텍스트끼리는 서로 import 하지 않는다. 화면이 calendar 의 연휴 날짜를 destination 과 itinerary 에 넘긴다.
- CQRS: 로그인, 일정 저장, 찜하기, 탈퇴만 쓰기(Command)이고 나머지는 읽기(Query)다. 저장할 때는 화면이 보낸 일정을 믿지 않고, 서버가 주소 값으로 다시 짠 일정을 그 순간 그대로(snapshot) 남긴다.

## 지키는 것

- 인증키는 서버에서만 쓴다. 공공데이터 URL 에는 키가 들어가므로 URL 과 에러 메시지를 로그에 남기지 않는다.
- `use cache` 함수는 실패를 던지지 않고 값으로 돌려준다. 던진 에러는 캐시 경계를 넘으면서 종류와 메시지를 잃는다.
- 바깥 API 가 실패해도 화면은 뜬다. 그 정보만 빠진다. 저장하다 실패하면 일정 화면으로 돌아가 다시 저장하라고 알린다.
- 로그인·저장 뒤 돌아갈 주소는 우리 사이트 안의 경로만 받는다(`safeNext`).
- 저장·찜 전에 계정이 아직 있는지 본다. 다른 기기에서 탈퇴한 세션은 끝내고 다시 로그인하게 한다.
- 날짜는 `2026.12.25(금)` 처럼 쓴다. 화면 문구는 해요체로 쓰고 줄표·쉼표·가운뎃점 대신 조사로 잇는다(`shared/kernel/korean`).

## 안드로이드 앱

`android/` 는 운영 사이트를 감싸는 TWA(Trusted Web Activity) 프로젝트다. Bubblewrap 으로 만들었고, 설정은 `android/twa-manifest.json` 에 있다(패키지 `com.hosunglee.holidaytrip`). 화면은 웹과 같아서 웹을 배포하면 앱도 바뀐다.

- 앱이 주소창 없이 열리려면 `public/.well-known/assetlinks.json` 에 서명 키 지문이 있어야 한다. Play 앱 서명을 쓰면 Play Console 의 앱 서명 키 SHA-256 도 넣는다.
- 서명 키(keystore)는 저장소 밖에 둔다. 커밋하지 않는다.
- 스토어 등록 이미지와 스크린샷은 `store/` 에 있다.
